# รายการตรวจบนเครื่องจริง

ใช้ตรวจเครื่องที่จะใช้ที่บูธ ก่อนวันงาน หลังตั้งค่าตาม [คู่มือตั้งค่าเครื่อง Windows](kiosk-setup-windows.md) เสร็จแล้ว ตรวจทีละข้อ ติ๊กช่องผ่านหรือไม่ผ่าน

**ถ้าข้อใดไม่ผ่าน ให้แจ้งกลับ**

- ข้อที่ไม่ผ่าน และสิ่งที่เห็นจริง
- เบราว์เซอร์และวิธีเปิดเกมที่ใช้ (วิธี ก ข หรือ ค ในหัวข้อที่ 4 ของคู่มือตั้งค่าเครื่อง)
- รุ่นของ Windows (กด Windows + R พิมพ์ `winver` แล้วกด Enter)
- รุ่นของเบราว์เซอร์ (เปิดเบราว์เซอร์แบบปกติ ไม่ใช่จากทางลัด Chrome: เมนู ⋮ > Help > About Google Chrome, Edge: เมนู ... > Help and feedback > About Microsoft Edge)
- ความละเอียดจอ (Settings > System > Display > Display resolution)
- ภาพถ่ายหน้าจอ หรือภาพถ่ายจากมือถือถ้าจับภาพหน้าจอไม่ได้

ตรวจทุกข้อโดยเปิดเกมจากทางลัดบนเดสก์ท็อป ทางลัดเดียวกับที่จะใช้ที่บูธ

## ส่วนที่ 1 การแสดงผลและการใช้งานพื้นฐาน

- [ ] **1. เต็มจอ** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ เปิดเกมจากทางลัด ดูว่าเกมเต็มจอแนวตั้งพอดี ไม่มีแถบของเบราว์เซอร์และไม่มีแถบงานของ Windows

- [ ] **2. เลื่อนหน้าและเลือกข้อความไม่ได้** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ลองเลื่อนหน้าด้วยนิ้วขึ้นลง ลองแตะค้างที่ข้อความ แล้วดูว่าหน้าไม่เลื่อนและไม่มีข้อความถูกเลือก (การซูมตรวจในข้อ 9, 11 และ 12)

- [ ] **3. ปัดจากขอบจอไม่เรียกเมนู Windows และไม่ออกจากเกม** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ปัดนิ้วเข้าจากขอบซ้าย ขวา บน และล่างของจอทีละขอบ ดูว่าไม่มีเมนูหรือแผงใดขึ้นมาทับเกม และเกมยังอยู่

- [ ] **4. ดึงเพื่อรีเฟรชไม่ทำงาน** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ใช้นิ้วลากจากบนลงล่างบนกระดานแรง ๆ ดูว่าหน้าไม่รีเฟรชและไม่ย้อนกลับ

- [ ] **5. เปิดเกมได้ตอนไม่มีอินเทอร์เน็ต และเล่นได้ครบรอบ** ผ่าน [ ] ไม่ผ่าน [ ]
  - ทำหลังหัวข้อที่ 6 ของคู่มือตั้งค่าเครื่อง (เปิดเกมจากทางลัดหนึ่งครั้งขณะมีอินเทอร์เน็ต) และทำแบบเดียวกับที่จะเปิดเกมที่บูธ
  - วิธีตรวจ
    1. ต่อคีย์บอร์ด กด Alt + F4 ปิดเกม แล้วปิดหน้าต่าง Chrome และ Edge อื่นที่เปิดอยู่ทั้งหมด
    2. ปิดอินเทอร์เน็ตของเครื่อง (ถอดสาย LAN และปิด Wi-Fi)
    3. ดับเบิลคลิกทางลัด `เกมจับคู่` บนเดสก์ท็อป ทางลัดเดียวกับที่จะใช้ที่บูธ
    4. เล่นให้ครบหนึ่งรอบ
    5. เปิดอินเทอร์เน็ตกลับ
  - ถ้าไม่ผ่าน ให้แจ้งว่าใช้เบราว์เซอร์อะไร ใช้วิธีไหน (วิธี ก ข หรือ ค ในหัวข้อที่ 4 ของคู่มือ) และเห็นอะไรบนจอหลังดับเบิลคลิกทางลัด
  - ถ้าใช้วิธี ค ให้ข้ามข้อนี้ เพราะวิธี ค ต้องมีอินเทอร์เน็ตทุกครั้งที่เปิดเกมอยู่แล้ว ให้เขียนในสรุปผลว่า "วิธี ค ต้องมีอินเทอร์เน็ตทุกครั้งที่เปิดเกม"

- [ ] **6. เล่นจริงครบรอบ** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ เล่นหนึ่งรอบจนหมดเวลา กดเริ่มเกมใหม่ แล้วเล่นอีกหนึ่งรอบ ดูว่าการแตะตอบสนองทันทีทุกครั้ง ไม่หน่วง ไม่พลาดการแตะ
  - ข้อยกเว้นที่ตั้งใจไว้ ไม่ต้องแจ้งว่าไม่ผ่าน ปุ่ม "เริ่มเกมใหม่" ในหน้าต่างผลลัพธ์จะไม่ตอบสนองประมาณ 1 วินาทีหลังจบรอบ ปุ่ม "เริ่มเกม" จะไม่ตอบสนองประมาณครึ่งวินาทีหลังกด "เริ่มเกมใหม่" และปุ่ม "เริ่มเกมใหม่" ข้างช่อง "เหลือเวลา" จะไม่ตอบสนองตลอดช่วงนับถอยหลังหลังกด "เริ่มเกม" กับอีกประมาณครึ่งวินาทีหลังฉากนับถอยหลังหายไป (การนับถอยหลังยกเลิกกลางคันไม่ได้) เพื่อกันการแตะพลาดที่ทำให้ผลลัพธ์หาย เริ่มรอบถัดไป หรือยกเลิกรอบที่เพิ่งเริ่มโดยไม่ตั้งใจ

- [ ] **7. กดเริ่มเกมใหม่แล้วไม่เห็นตัวเลขของรอบถัดไป** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ เล่นหนึ่งรอบจนหมดเวลา (การ์ดทุกใบหงายให้เห็นตัวเลข) รอประมาณ 1 วินาที แล้วกด "เริ่มเกมใหม่" ในหน้าต่างผลลัพธ์ ระหว่างกดให้มองที่กระดาน การ์ดทุกใบต้องคว่ำทันที และต้องไม่เห็นตัวเลขบนการ์ดใบใดเลยแม้แวบเดียว จนกว่าจะกด "เริ่มเกม"
  - ถ้าทำได้ ให้ใช้มือถือถ่ายวิดีโอกระดานตอนกด แล้วเปิดดูช้า ๆ ถ้าเห็นตัวเลขแวบขึ้นมา ให้ทำเครื่องหมายไม่ผ่านและแนบวิดีโอ

- [ ] **8. แตะ "เริ่มเกม" สองครั้งเร็ว ๆ แล้วรอบยังเดินต่อ** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ที่หน้าเริ่มเกม แตะปุ่ม "เริ่มเกม" สองครั้งติดกันเร็ว ๆ จะเห็นฉากนับถอยหลัง 3, 2, 1, "เริ่ม!" ตามปกติ (ดูข้อ 15) หลังนับจบ ดูว่ารอบเริ่มและเวลานับถอยหลังต่อไปเรื่อย ๆ ปุ่มเปลี่ยนเป็น "เริ่มเกมใหม่" และเกมไม่กลับไปหน้าเริ่มเกม

## ส่วนที่ 2 การกันการซูมและการลากรูป

- [ ] **9. ใช้สองนิ้วถ่างหรือหนีบ หน้าไม่ซูม** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ใช้สองนิ้วถ่างออกและหนีบเข้าบนกระดาน ดูว่าขนาดหน้าไม่เปลี่ยน

- [ ] **10. แตะค้างแล้วไม่มีเมนูขึ้น** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ใช้นิ้วแตะค้างที่การ์ด ปุ่ม และพื้นหลังประมาณ 2 วินาทีทีละจุด ดูว่าไม่มีเมนูขึ้นมา

- [ ] **11. ต่อคีย์บอร์ดและเมาส์ กด Ctrl ค้างแล้วหมุนล้อเมาส์ หน้าไม่ซูม** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ กด Ctrl ค้างไว้ แล้วหมุนล้อเมาส์ขึ้นและลง ดูว่าขนาดหน้าไม่เปลี่ยน

- [ ] **12. ต่อคีย์บอร์ด กด Ctrl กับ + - หรือ 0 หน้าไม่ซูม** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ กด Ctrl + `+`, Ctrl + `-` และ Ctrl + `0` ทีละคู่ ดูว่าขนาดหน้าไม่เปลี่ยน
  - จากนั้นกด Windows + Space เพื่อสลับแป้นพิมพ์เป็นภาษาไทย แล้วกดสามคู่เดิมที่ปุ่มเดิมซ้ำอีกครั้ง ขนาดหน้าต้องไม่เปลี่ยนเช่นกัน

- [ ] **13. ลากรูปแล้วไม่มีอะไรเกิดขึ้น** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ใช้เมาส์หรือนิ้วกดที่รูปในเกม (โลโก้ การ์ด รูปรางวัล) แล้วลาก ดูว่ารูปไม่ถูกดึงออกมาและไม่มีภาพเงาลอยตามนิ้ว

## ส่วนที่ 3 การกันจอดับ

- [ ] **14. จอไม่ดับเมื่อตั้งทิ้งไว้** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ เปิดเกมค้างไว้ที่หน้าเริ่มเกมโดยไม่แตะจอ 15 นาที แล้วดูว่าจอยังสว่าง ไม่มีภาพพักหน้าจอ และเกมยังอยู่
  - หมายเหตุ ฟีเจอร์กันจอดับของเบราว์เซอร์ทำงานเฉพาะเมื่อเปิดเกมผ่าน HTTPS ส่วนการตั้ง Screen and sleep เป็น Never ในหัวข้อที่ 2 ของคู่มือตั้งค่าเครื่องเป็นตัวกันจอดับที่เชื่อถือได้ไม่ว่ากรณีใด ถ้าข้อนี้ไม่ผ่าน ให้ตรวจการตั้งค่านั้น และการปิดภาพพักหน้าจอในหัวข้อที่ 3 ก่อน

## ส่วนที่ 4 การนับถอยหลังก่อนเริ่มเกม

- [ ] **15. กด "เริ่มเกม" แล้วมีฉากนับถอยหลัง และแตะอะไรไม่ได้จนกว่าจะนับจบ** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ที่หน้าเริ่มเกม กด "เริ่มเกม" หนึ่งครั้ง ต้องเห็นฉากสีดำโปร่งใสคลุมทั้งจอจนถึงขอบทุกด้าน กลางจอแสดงเลข 3 แล้ว 2 แล้ว 1 เลขละประมาณ 1 วินาที ตามด้วยคำว่า "เริ่ม!" จากนั้นฉากดำหายไป และตัวเลขเวลาเริ่มเดินจาก 25
  - ระหว่างที่ฉากดำยังอยู่ ให้ลองแตะการ์ดและแตะปุ่มบนแถบด้านบน ต้องไม่มีอะไรเกิดขึ้น การ์ดทุกใบต้องคว่ำอยู่ และต้องไม่เห็นตัวเลขบนการ์ดใบใด
  - ถ้าไม่ผ่าน ให้แจ้งว่าเห็นอะไรบนจอ (เช่น ฉากดำไม่ถึงขอบจอ แตะการ์ดแล้วเปิดได้ หรือเวลาเดินก่อนฉากดำหาย)

## ส่วนที่ 5 หน้าตั้งค่าของเจ้าหน้าที่

ทำส่วนนี้หลังตั้งรหัส PIN ตามหัวข้อที่ 8 ของคู่มือตั้งค่าเครื่องแล้ว

- [ ] **16. กดค้างที่ชื่อคลินิก 3 วินาทีแล้วหน้าตั้งค่าขึ้น และขึ้นเฉพาะที่หน้าเริ่มเกม** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ ที่หน้าเริ่มเกม ใช้นิ้วกดค้างที่ชื่อ "V Square Clinic" 3 วินาทีโดยไม่ขยับนิ้ว ต้องเห็นฉากสีดำคลุมทั้งจอจนถึงขอบทุกด้าน และแป้นตัวเลขให้ใส่รหัส PIN จากนั้นกด "ยกเลิก" เพื่อปิด
  - แตะที่ชื่อคลินิกสั้น ๆ หนึ่งครั้ง และกดค้างประมาณ 1 วินาทีแล้วปล่อยอีกหนึ่งครั้ง ต้องไม่มีอะไรเกิดขึ้น
  - กด "เริ่มเกม" รอจนรอบเริ่ม แล้วกดค้างที่ชื่อคลินิก 3 วินาที ต้องไม่มีอะไรเกิดขึ้น และเกมเล่นต่อได้ตามปกติ
  - ถ้าไม่ผ่าน ให้แจ้งว่ากดค้างแล้วเห็นอะไร (เช่น ไม่มีอะไรขึ้นเลย มีเมนูหรือกรอบสี่เหลี่ยมของ Windows ขึ้นมา หรือหน้าตั้งค่าขึ้นระหว่างรอบ)

- [ ] **17. ค่าที่บันทึกมีผลกับรอบถัดไป และยังอยู่หลังปิดแล้วเปิดเกมใหม่** ผ่าน [ ] ไม่ผ่าน [ ]
  - วิธีตรวจ เปิดหน้าตั้งค่า ใส่รหัส PIN กด +5 ที่ "เวลาเล่นต่อรอบ" แล้วกด "บันทึก" ตัวเลขเวลาบนจอต้องเปลี่ยนเป็นค่าใหม่ทันที (เช่น จาก 25 เป็น 30)
  - ต่อคีย์บอร์ด กด Alt + F4 เพื่อปิดเกม แล้วเปิดจากทางลัดอีกครั้ง ตัวเลขเวลาต้องยังเป็นค่าใหม่ และเมื่อกดค้างที่ชื่อคลินิก เกมต้องถามรหัส PIN เดิม ไม่ใช่ให้ตั้งรหัสใหม่ (ถ้าเปิดเกมด้วยวิธี ค ขั้นนี้จะไม่ผ่าน ซึ่งเป็นไปตามที่คู่มือตั้งค่าเครื่องอธิบายไว้)
  - เปิดหน้าตั้งค่าค้างไว้โดยไม่แตะจอ 30 วินาที หน้าตั้งค่าต้องปิดเอง
  - เมื่อตรวจเสร็จ ให้เปิดหน้าตั้งค่าอีกครั้ง กด "คืนค่าเริ่มต้น" แล้วกด "บันทึก" หรือปรับเป็นค่าที่จะใช้ในวันงาน
  - ถ้าไม่ผ่าน ให้แจ้งว่าขั้นใดไม่เป็นไปตามนี้ และหน้าตั้งค่ามีข้อความ "เครื่องนี้เก็บค่าไม่ได้" หรือไม่
