# คู่มือตั้งค่าเครื่อง Windows ที่บูธ

คู่มือนี้สำหรับเจ้าหน้าที่ที่ตั้งเครื่องที่บูธ ไม่ต้องเป็นนักพัฒนา ทำตามเลขข้อทีละข้อ ทำหนึ่งอย่างต่อหนึ่งข้อ

ก่อนเริ่ม เตรียมสิ่งเหล่านี้

- ลิงก์ของเกม (ขึ้นต้นด้วย `https://`) จากเจ้าของงาน
- อินเทอร์เน็ตสำหรับการตั้งค่าครั้งแรก
- คีย์บอร์ดและเมาส์ สำหรับตั้งค่าและสำหรับออกจากเกม
- บัญชี Windows ที่เป็นผู้ดูแลระบบ (Administrator)

เมื่อตั้งค่าครบแล้ว ให้ทำตาม [รายการตรวจบนเครื่องจริง](on-device-checklist.md) ก่อนวันงาน

## 1. หมุนจอเป็นแนวตั้ง

1. คลิกขวาที่พื้นที่ว่างบนเดสก์ท็อป เลือก Display settings
2. ในหน้า Settings > System > Display หาหัวข้อ Display orientation
3. เลือก Portrait
4. กด Keep changes

## 2. ตั้งไม่ให้จอดับและเครื่องไม่หลับ

1. เปิด Settings > System > Power
2. เปิดหัวข้อ Screen and sleep
3. ตั้งทุกช่องเป็น Never (ทั้งแบบเสียบปลั๊กและแบบใช้แบตเตอรี่ ถ้ามี)

ข้อนี้สำคัญ เพราะเป็นตัวกันจอดับที่เชื่อถือได้ที่สุด ส่วนการกันจอดับของตัวเกมเองใช้ได้เฉพาะเมื่อเปิดผ่าน HTTPS

## 3. เปิดเกมหนึ่งครั้งขณะมีอินเทอร์เน็ต

1. เปิด Microsoft Edge ตามปกติ (ไม่ใช่โหมดเต็มจอ)
2. พิมพ์ลิงก์ของเกมที่แถบที่อยู่ แล้วกด Enter
3. รอจนเห็นกระดานเกม
4. กด F5 หนึ่งครั้งเพื่อโหลดหน้าใหม่ รอจนเห็นกระดานอีกครั้ง

ขั้นนี้ทำให้เบราว์เซอร์เก็บไฟล์เกมไว้ในเครื่อง หลังจากนี้เกมเปิดได้แม้ไม่มีอินเทอร์เน็ต ต้องทำผ่านเบราว์เซอร์ตัวเดียวกันกับที่จะใช้ที่บูธ (ถ้าจะใช้ Chrome ให้ทำข้อนี้ใน Chrome ด้วย)

## 4. สร้างทางลัดบนเดสก์ท็อป

ใช้ Edge (แนะนำ)

1. คลิกขวาที่พื้นที่ว่างบนเดสก์ท็อป เลือก New > Shortcut
2. ที่ช่อง "Type the location of the item" วางข้อความด้านล่างนี้ โดยแทน `<ลิงก์ของเกม>` ด้วยลิงก์จริง (เก็บเครื่องหมายคำพูดไว้ตามเดิม)

   ```
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk "<ลิงก์ของเกม>" --edge-kiosk-type=fullscreen --no-first-run --disable-pinch --overscroll-history-navigation=0
   ```

3. กด Next
4. ตั้งชื่อทางลัดว่า `เกมจับคู่` แล้วกด Finish
5. ดับเบิลคลิกทางลัดเพื่อทดลอง เกมต้องขึ้นเต็มจอ

ถ้าไม่พบไฟล์ msedge.exe ที่พาธข้างต้น (Edge บางเครื่องอยู่ที่ `C:\Program Files\Microsoft\Edge\Application\msedge.exe`) ให้แก้พาธให้ตรงกับเครื่อง

ทางเลือกสำหรับ Chrome (ถ้าไม่ใช้ Edge) ใช้ข้อความนี้ในขั้นที่ 2 แทน

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "<ลิงก์ของเกม>" --no-first-run --disable-pinch --overscroll-history-navigation=0
```

ข้อควรรู้เรื่องชื่อ flag

- `--kiosk`, `--edge-kiosk-type=fullscreen` และ `--no-first-run` พบได้ในแหล่งข้อมูลหลายแหล่งว่าใช้งานได้กับ Edge รุ่นปัจจุบัน แต่หน้าเอกสารทางการของ Microsoft ที่ตรวจได้ยังเป็นรุ่นเก่า จึงยืนยันกับเอกสารปัจจุบันไม่ได้เต็มที่ ตรวจผลตามรายการตรวจบนเครื่องจริง
- `--disable-pinch` และ `--overscroll-history-navigation=0` ยืนยันกับเอกสารทางการของ Chromium ไม่ได้ พบเฉพาะในคู่มือของชุมชน ตัวเกมเองมีการกันซูมและการดึงเพื่อรีเฟรชอยู่แล้ว flag สองตัวนี้เป็นชั้นเสริม ตรวจผลตามรายการตรวจบนเครื่องจริง ถ้า flag ใดไม่ได้ผลก็ไม่ทำให้เกมเสีย

## 5. ปิดท่าทางปัดจากขอบจอ

ท่าทางปัดจากขอบจออาจเรียกเมนูของ Windows ขึ้นมาทับเกม วิธีที่ 1 ใช้ได้กับ Windows Pro, Enterprise และ Education ส่วน Windows Home ไม่มีโปรแกรมนี้ ให้ใช้วิธีที่ 2

วิธีที่ 1 Group Policy

1. กดปุ่ม Windows + R พิมพ์ `gpedit.msc` แล้วกด Enter
2. ไปที่ Computer Configuration > Administrative Templates > Windows Components > Edge UI
3. ดับเบิลคลิก Allow edge swipe
4. เลือก Disabled แล้วกด OK

วิธีที่ 2 Registry (ใช้กับ Windows Home ได้)

1. กดปุ่ม Windows + R พิมพ์ `regedit` แล้วกด Enter
2. ไปที่ `HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows`
3. ถ้าไม่มีคีย์ชื่อ `EdgeUI` ให้คลิกขวาที่ `Windows` เลือก New > Key แล้วตั้งชื่อ `EdgeUI`
4. คลิกขวาที่ `EdgeUI` เลือก New > DWORD (32-bit) Value ตั้งชื่อ `AllowEdgeSwipe`
5. ดับเบิลคลิก `AllowEdgeSwipe` ตั้งค่า Value data เป็น `0` แล้วกด OK

จากนั้น

6. รีสตาร์ตเครื่อง

ข้อควรรู้ ชื่อ policy และค่า `0` ตรงกับเอกสารของ Microsoft แต่มีผู้ใช้รายงานว่าบน Windows 11 บางเครื่อง การตั้งนี้ไม่ได้ผลเต็มที่ และไดรเวอร์จอสัมผัสของบางยี่ห้อมีท่าทางของตัวเอง ตรวจผลตามรายการตรวจบนเครื่องจริง และแจ้งกลับถ้ายังปัดจากขอบจอแล้วมีเมนูขึ้น

## 6. วิธีออกจากเกม

1. ต่อคีย์บอร์ด
2. กด Alt + F4

## 7. ถ้าเกมไม่ขึ้นหรือค้าง

1. ต่อคีย์บอร์ด แล้วกด Alt + F4 เพื่อปิด
2. ดับเบิลคลิกทางลัด `เกมจับคู่` บนเดสก์ท็อปเพื่อเปิดใหม่
3. เกมเปิดได้แม้ไม่มีอินเทอร์เน็ต ถ้าได้ทำขั้นตอนที่ 3 ไว้แล้ว
4. ถ้ายังไม่ขึ้น ให้รีสตาร์ตเครื่อง แล้วเปิดจากทางลัดอีกครั้ง
