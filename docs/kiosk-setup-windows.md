# คู่มือตั้งค่าเครื่อง Windows ที่บูธ

คู่มือนี้สำหรับเจ้าหน้าที่ที่ตั้งเครื่องที่บูธ ไม่ต้องเป็นนักพัฒนา ทำตามเลขข้อทีละข้อ ทำหนึ่งอย่างต่อหนึ่งข้อ

ก่อนเริ่ม เตรียมสิ่งเหล่านี้

- ลิงก์ของเกม (ขึ้นต้นด้วย `https://`) จากเจ้าของงาน ใช้ตามที่ได้รับทุกตัวอักษร ห้ามตัดเครื่องหมาย `/` ท้ายลิงก์ออก
- อินเทอร์เน็ตสำหรับการตั้งค่า
- คีย์บอร์ดและเมาส์ สำหรับตั้งค่าและสำหรับออกจากเกม
- บัญชี Windows ที่เป็นผู้ดูแลระบบ (Administrator)

เมื่อตั้งค่าครบแล้ว ให้ทำตาม [รายการตรวจบนเครื่องจริง](on-device-checklist.md) ก่อนวันงาน

## 1. หมุนจอเป็นแนวตั้ง

1. คลิกขวาที่พื้นที่ว่างบนเดสก์ท็อป เลือก Display settings
2. ในหน้า Settings > System > Display หาหัวข้อ Display orientation
3. เลือก Portrait
4. กด Keep changes

## 2. ตั้งไม่ให้จอดับและเครื่องไม่หลับ

1. เปิด Settings > System > Power
2. เปิดหัวข้อ Screen and sleep
3. ตั้งทุกช่องเป็น Never (ทั้งแบบเสียบปลั๊กและแบบใช้แบตเตอรี่ ถ้ามี)

ชื่อหัวข้อบน Windows แต่ละรุ่นอาจต่างกันเล็กน้อย เช่น "Screen, sleep, & hibernate timeouts" ให้ตั้งทุกช่องที่เกี่ยวกับการดับจอและการหลับเป็น Never

ข้อนี้สำคัญ เพราะเป็นตัวกันจอดับที่เชื่อถือได้ที่สุด ส่วนการกันจอดับของตัวเกมเองใช้ได้เฉพาะเมื่อเปิดผ่าน HTTPS

## 3. ปิดสิ่งที่อาจขึ้นมาทับเกมระหว่างงาน

ชื่อเมนูด้านล่างเป็นของ Windows 11 บน Windows รุ่นอื่นชื่ออาจต่างกันเล็กน้อย เช่น บน Windows 10 อัปเดตอยู่ที่ Settings > Update & Security > Windows Update และการแจ้งเตือนอยู่ที่ Settings > System > Notifications & actions

1. ปิดภาพพักหน้าจอ เปิด Settings > Personalization > Lock screen กด Screen saver (ในหัวข้อ Related settings) ในหน้าต่าง Screen Saver Settings ที่ขึ้นมา ตั้งช่อง Screen saver เป็น (None) แล้วกด OK
2. ปิดการแจ้งเตือน เปิด Settings > System > Notifications แล้วปิดสวิตช์ Notifications ให้เป็น Off (ถ้าเครื่องไม่มีสวิตช์นี้ ให้เปิด Do not disturb เป็น On แทน)
3. หยุด Windows Update ชั่วคราวสำหรับสัปดาห์ของงาน ทำข้อนี้ภายใน 1–2 วันก่อนวันงาน เปิด Settings > Windows Update ที่ Pause updates เลือกระยะเวลาให้ครอบคลุมทุกวันของงาน (เช่น Pause for 1 week)

ถ้าหน้า Windows Update มีปุ่ม Restart now แปลว่ามีอัปเดตรอรีสตาร์ตอยู่ ให้รีสตาร์ตเครื่องให้เสร็จก่อนวันงาน

## 4. เลือกวิธีเปิดเกม

อ่านหัวข้อนี้ก่อน แล้วเลือกหนึ่งวิธี

เกมจะเปิดได้ตอนไม่มีอินเทอร์เน็ต ก็ต่อเมื่อเบราว์เซอร์เก็บไฟล์เกมไว้ในเครื่องแล้ว เบราว์เซอร์เก็บไฟล์ตอนเปิดเกมขณะมีอินเทอร์เน็ต และเก็บไว้ในโปรไฟล์ (ที่เก็บข้อมูล) ที่ใช้เปิดเกมครั้งนั้น ไฟล์จึงใช้ได้เฉพาะเมื่อเปิดเกมด้วยเบราว์เซอร์เดียวกันและวิธีเดียวกัน คู่มือนี้จึงให้เปิดเกมครั้งแรกจากทางลัดที่จะใช้ที่บูธ (หัวข้อที่ 6) วิธี ก และวิธี ข เก็บไฟล์ไว้ได้ วิธี ค ไม่เก็บ

**วิธี ก Chrome โหมด kiosk (แนะนำ)**

- เกมขึ้นเต็มจอ ไม่มีแถบของเบราว์เซอร์
- ใช้โปรไฟล์ของตัวเองที่เก็บไว้ในโฟลเดอร์ `C:\GameKiosk\Chrome` ในเครื่อง ไม่ใช่หน้าต่างส่วนตัว (InPrivate หรือ Incognito) จึงเปิดเกมได้แม้ไม่มีอินเทอร์เน็ต หลังทำหัวข้อที่ 6 แล้ว (ยืนยันด้วยข้อ 5 ของรายการตรวจบนเครื่องจริง)
- ต้องมี Google Chrome ในเครื่อง ถ้ายังไม่มีและติดตั้งได้ ให้ติดตั้งจาก `https://www.google.com/chrome/` ก่อน ถ้าติดตั้งไม่ได้ ให้ใช้วิธี ข

**วิธี ข Edge โหมดแอปเต็มจอ (สำหรับเครื่องที่ไม่มี Chrome)**

- เกมขึ้นในหน้าต่างแอปแบบเต็มจอ ไม่มีแถบที่อยู่
- ใช้โปรไฟล์ของตัวเองที่เก็บไว้ในโฟลเดอร์ `C:\GameKiosk\Edge` จึงเปิดเกมได้แม้ไม่มีอินเทอร์เน็ต หลังทำหัวข้อที่ 6 แล้ว เหมือนวิธี ก (ยืนยันด้วยข้อ 5 ของรายการตรวจบนเครื่องจริง)
- สิ่งที่วิธีนี้ไม่ได้ล็อก วิธีนี้ไม่ใช่โหมด kiosk ถ้ามีคีย์บอร์ดต่ออยู่ ใครก็กด F11 ออกจากโหมดเต็มจอได้ และใช้ปุ่มลัดอื่นของเบราว์เซอร์ได้ (เช่น เปิดหน้าต่างใหม่) ให้ถอดคีย์บอร์ดและเมาส์ออกระหว่างงาน

**วิธี ค Edge โหมด kiosk (ใช้เฉพาะเมื่อเครื่องมีอินเทอร์เน็ตทุกครั้งที่เปิดเกม)**

- ล็อกได้รัดกุมที่สุด Microsoft ระบุว่าโหมดนี้กันปุ่ม F11 (ออกจากเต็มจอ) และ F12 (เครื่องมือของนักพัฒนา)
- แต่ Microsoft ระบุว่าโหมด kiosk ของ Edge ทำงานเป็นหน้าต่าง InPrivate ซึ่งไม่เก็บข้อมูลของเว็บไว้ในเครื่องหลังปิด ผลคือเกมถูกดาวน์โหลดใหม่ทุกครั้งที่เปิดทางลัด และ**เครื่องต้องมีอินเทอร์เน็ตทุกครั้งที่เปิดทางลัด** ถ้าเปิดตอนไม่มีอินเทอร์เน็ต เกมจะไม่ขึ้น
- ถ้าอินเทอร์เน็ตหลุดหลังจากเกมขึ้นมาแล้ว เกมที่เปิดค้างอยู่ยังเล่นต่อได้ แต่ถ้าปิดแล้วจะเปิดใหม่ไม่ได้จนกว่าอินเทอร์เน็ตจะกลับมา

## 5. สร้างทางลัดบนเดสก์ท็อป

1. คลิกขวาที่พื้นที่ว่างบนเดสก์ท็อป เลือก New > Shortcut
2. ที่ช่อง "Type the location of the item" วางข้อความของวิธีที่เลือกในหัวข้อที่ 4 (เลือกข้อความเดียวจากสามข้อความด้านล่าง)

   วิธี ก Chrome โหมด kiosk

   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "<ลิงก์ของเกม>" --user-data-dir=C:\GameKiosk\Chrome --no-first-run --disable-pinch
   ```

   วิธี ข Edge โหมดแอปเต็มจอ

   ```
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --app="<ลิงก์ของเกม>" --start-fullscreen --user-data-dir=C:\GameKiosk\Edge --no-first-run --disable-pinch
   ```

   วิธี ค Edge โหมด kiosk

   ```
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk "<ลิงก์ของเกม>" --edge-kiosk-type=fullscreen --no-first-run --disable-pinch
   ```

3. ในข้อความที่วางแล้ว แทนที่ `<ลิงก์ของเกม>` ด้วยลิงก์จริงของเกม ต้องลบเครื่องหมาย `<` และ `>` ออกด้วย และเก็บเครื่องหมายคำพูด `"` สองข้างของลิงก์ไว้ตามเดิม (ทำข้อนี้ทุกวิธี)
4. กด Next
5. ตั้งชื่อทางลัดว่า `เกมจับคู่` แล้วกด Finish
6. คลิกขวาที่ทางลัด เลือก Properties แล้วดูช่อง Target (ทำข้อนี้ทุกวิธี) ลิงก์เต็มของเกมต้องอยู่ในเครื่องหมายคำพูดครบทุกตัวอักษร และตัวเลือกที่ตามหลังลิงก์ (ขึ้นต้นด้วย `--`) ต้องอยู่ครบตามข้อความในขั้นที่ 2 ข้อความในช่อง Target ต้องจบด้วย `--disable-pinch` (ตัวช่วยสร้างทางลัดรับข้อความได้ประมาณ 260 ตัวอักษร ถ้าลิงก์ยาว ท้ายข้อความอาจถูกตัด) ถ้าขาด ให้แก้ในช่อง Target ให้ครบ แล้วกด OK

ถ้าไม่พบไฟล์ของเบราว์เซอร์ที่พาธข้างต้น ให้แก้พาธในข้อความให้ตรงกับเครื่อง

- Chrome บางเครื่องอยู่ที่ `C:\Program Files (x86)\Google\Chrome\Application\chrome.exe`
- Edge บางเครื่องอยู่ที่ `C:\Program Files\Microsoft\Edge\Application\msedge.exe`

ไม่ต้องสร้างโฟลเดอร์ `C:\GameKiosk` เอง เบราว์เซอร์สร้างให้ตอนเปิดทางลัดครั้งแรก

ข้อควรรู้เรื่องตัวเลือกในข้อความ

- ยืนยันกับเอกสารทางการแล้ว
  - `--kiosk`, `--edge-kiosk-type=fullscreen` และ `--no-first-run` ของ Edge อยู่ในหน้า "Configure Microsoft Edge kiosk mode" ของ Microsoft ฉบับปัจจุบัน หน้าเดียวกันนี้ระบุว่าโหมด kiosk ของ Edge ทำงานเป็นหน้าต่าง InPrivate
  - `--kiosk`, `--app`, `--start-fullscreen`, `--no-first-run` และ `--disable-pinch` อยู่ในรายการตัวเลือกของ Chromium ซึ่งเป็นโค้ดที่ทั้ง Chrome และ Edge สร้างขึ้นมา `--user-data-dir` อยู่ในเอกสารของ Chromium และหน้าเอกสารนโยบายของ Edge ระบุว่า Edge รับตัวเลือกนี้
- ยังยืนยันไม่ได้ ให้ตรวจผลด้วยรายการตรวจบนเครื่องจริง
  - Google ไม่มีเอกสารทางการที่บอกว่า `--kiosk` ของ Chrome บน Windows เก็บข้อมูลของเว็บไว้อย่างไร ข้อ 5 ของรายการตรวจ (เปิดเกมตอนไม่มีอินเทอร์เน็ต) เป็นตัวตัดสิน
  - Microsoft ไม่ได้ระบุ `--app`, `--start-fullscreen` และ `--disable-pinch` ไว้ในเอกสารของ Edge ข้อ 1 (เต็มจอ) และข้อ 9 (หนีบสองนิ้ว) ของรายการตรวจเป็นตัวตัดสิน
  - ผลที่ว่าวิธี ค เปิดเกมไม่ได้ตอนไม่มีอินเทอร์เน็ต อนุมานจากเอกสารของ Microsoft ยังไม่ได้ลองบนเครื่องจริง
- `--disable-pinch` เป็นชั้นเสริม ตัวเกมกันการซูมเองอยู่แล้ว ถ้าตัวเลือกนี้ไม่ได้ผลก็ไม่ทำให้เกมเสีย
- คู่มือฉบับก่อนมี `--overscroll-history-navigation=0` ไม่ต้องใส่แล้ว ตัวเลือกนี้ไม่อยู่ในรายการตัวเลือกปัจจุบันของ Chromium ตัวเกมกันการดึงเพื่อรีเฟรชเองอยู่แล้ว ข้อ 4 ของรายการตรวจเป็นตัวตรวจ
- `--user-data-dir` ทำให้ทางลัดเปิดเบราว์เซอร์ชุดใหม่ที่ใช้โปรไฟล์ของเกมเสมอ แม้มีหน้าต่าง Chrome หรือ Edge อื่นเปิดอยู่ (ถ้าไม่ใส่ ทางลัดอาจส่งลิงก์ไปเปิดในหน้าต่างที่เปิดอยู่แล้ว และตัวเลือกอื่นอาจไม่มีผล)

## 6. เปิดเกมจากทางลัดหนึ่งครั้งขณะมีอินเทอร์เน็ต

ขั้นนี้ทำให้เบราว์เซอร์เก็บไฟล์เกมไว้ในเครื่อง ต้องเปิดจากทางลัดในหัวข้อที่ 5 เท่านั้น การเปิดลิงก์ในหน้าต่าง Chrome หรือ Edge แบบปกติไม่ช่วย เพราะไฟล์จะถูกเก็บไว้คนละโปรไฟล์กับที่ทางลัดใช้

1. ตรวจว่าเครื่องต่ออินเทอร์เน็ตอยู่
2. ดับเบิลคลิกทางลัด `เกมจับคู่` บนเดสก์ท็อป
3. รอจนเห็นกระดานเกมเต็มจอ
4. รออีกประมาณ 30 วินาทีโดยไม่ปิดเกม ระหว่างนี้เบราว์เซอร์เก็บไฟล์เกมจนครบ
5. กด Alt + F4 เพื่อปิด
6. ดับเบิลคลิกทางลัดอีกครั้ง รอจนเห็นกระดานเกม
7. กด Alt + F4 เพื่อปิด

หลังทำขั้นนี้ วิธี ก และวิธี ข จะเปิดเกมได้แม้ไม่มีอินเทอร์เน็ต ตรวจให้แน่ใจด้วยข้อ 5 ของรายการตรวจบนเครื่องจริง ส่วนวิธี ค ขั้นนี้เป็นเพียงการทดลองว่าทางลัดใช้ได้ เพราะวิธี ค ต้องมีอินเทอร์เน็ตทุกครั้งที่เปิด

## 7. ปิดท่าทางปัดจากขอบจอ

ท่าทางปัดจากขอบจออาจเรียกเมนูของ Windows ขึ้นมาทับเกม

ข้อควรรู้ก่อนทำ Microsoft ระบุการตั้งค่านี้ไว้สำหรับ Windows Pro, Enterprise และ Education เท่านั้น บน Windows Home การตั้งค่านี้อาจไม่มีผลเลย และมีรายงานว่าบน Windows 11 บางเครื่องและบางไดรเวอร์จอสัมผัสก็ไม่ได้ผลเต็มที่ ให้ทำตามวิธีด้านล่างเป็นสิ่งที่ลองทำ แล้วใช้ข้อ 3 ของ [รายการตรวจบนเครื่องจริง](on-device-checklist.md) (ปัดจากขอบจอ) เป็นตัวตัดสินว่าได้ผลหรือไม่ ถ้าข้อ 3 ไม่ผ่าน ให้แจ้งผู้รับผิดชอบเกม พร้อมรุ่นของ Windows (Home หรือ Pro ฯลฯ) และเลขรุ่น (ดูจาก `winver`)

วิธีที่ 1 Group Policy (เฉพาะ Windows Pro, Enterprise และ Education เพราะ Windows Home ไม่มีโปรแกรมนี้)

1. กดปุ่ม Windows + R พิมพ์ `gpedit.msc` แล้วกด Enter
2. ไปที่ Computer Configuration > Administrative Templates > Windows Components > Edge UI
3. ดับเบิลคลิก Allow edge swipe
4. เลือก Disabled แล้วกด OK
5. รีสตาร์ตเครื่อง

วิธีที่ 2 Registry (ใช้กับ Windows Home ได้ แต่อาจไม่มีผล ให้ลองแล้วตรวจตามข้อ 3 ของรายการตรวจ)

1. กดปุ่ม Windows + R พิมพ์ `regedit` แล้วกด Enter
2. ไปที่ `HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows`
3. ถ้าไม่มีคีย์ชื่อ `EdgeUI` ให้คลิกขวาที่ `Windows` เลือก New > Key แล้วตั้งชื่อ `EdgeUI`
4. คลิกขวาที่ `EdgeUI` เลือก New > DWORD (32-bit) Value ตั้งชื่อ `AllowEdgeSwipe`
5. ดับเบิลคลิก `AllowEdgeSwipe` ตั้งค่า Value data เป็น `0` แล้วกด OK
6. รีสตาร์ตเครื่อง

## 8. วิธีออกจากเกม

1. ต่อคีย์บอร์ด
2. กด Alt + F4

## 9. ถ้าเกมไม่ขึ้นหรือค้าง

1. ต่อคีย์บอร์ด แล้วกด Alt + F4 เพื่อปิด
2. ดับเบิลคลิกทางลัด `เกมจับคู่` บนเดสก์ท็อปเพื่อเปิดใหม่
3. ถ้ายังไม่ขึ้น ให้รีสตาร์ตเครื่อง แล้วเปิดจากทางลัดอีกครั้ง

วิธี ก และวิธี ข เปิดเกมได้แม้ไม่มีอินเทอร์เน็ต ถ้าได้ทำหัวข้อที่ 6 ไว้แล้ว วิธี ค เปิดเกมได้เฉพาะเมื่อเครื่องมีอินเทอร์เน็ต ถ้าใช้วิธี ค และอินเทอร์เน็ตหลุด ให้ต่ออินเทอร์เน็ตให้ได้ก่อนเปิดทางลัด
